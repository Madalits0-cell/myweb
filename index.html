About Me

Hello! I am a Computer Science student at Mulungushi University in Zambia. I am interested in technology, computers and how websites are created. My studies are helping me develop problem-solving, programming and communication skills. I believe that consistent practice is important for learning new things. This personal website is part of my ICT251 Web Technologies activity. Through this project, I am learning how to structure web pages using HTML and style them using CSS. My goal is to become confident in creating attractive, useful and responsive websites that work on computers and phones.

My Hobbies

My Learning Plan

I will improve my web development skills through regular practice, research and small personal projects.

  1. Practise HTML headings, paragraphs, links, lists and forms.
  2. Learn CSS colours, selectors, spacing and page layouts.
  3. Build and test responsive websites on different screens.
  4. Study JavaScript to add interactive features to websites.
