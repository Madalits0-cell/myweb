
# Madalitso Mwamba — Personal Student Website

## Project Description

This is my personal student website for ICT251 Web Technologies Activity 3 at Mulungushi University. It introduces me, my hobbies, learning plan, photos, media, and developing web development skills as a second-year Bachelor of Science in Cyber Security student.

The website uses HTML for structure, CSS for styling and responsive layouts, and JavaScript for interactive features.

## Main Sections

- About Me
- My Hobbies
- My Learning Plan and Study Schedule
- My Photos
- My Media
- Projects and Skills
- Contact Form

## JavaScript Features

1. **Contact form validation and preview:** Checks required fields, rejects whitespace-only names and messages, validates the email format, and displays a preview without reloading the page. It does not send messages.
2. **Theme switch:** Allows visitors to switch between light and dark themes.
3. **Project search:** Filters the project cards as the visitor types and provides a button to show all projects.
4. **Expandable project details:** Allows visitors to open and close additional information about each project.

## Files and Folders

- `index.html` — website content and structure
- `css/styles.css` — styling, layout, and responsive design
- `js/script.js` — JavaScript interactivity
- `images/` — website photos
- `videos/` — video and audio files

## Testing

The website should be tested locally and after deployment.

- Check that all navigation links reach the correct sections.
- Confirm that images, video, and audio load and have controls.
- Submit the contact form with empty fields, whitespace-only text, an invalid email, and valid details.
- Test the theme switch, project search, reset button, and project detail buttons.
- Check the layout at approximately 375px and 1280px viewport widths.
- Test keyboard focus and confirm that the page does not have unintended horizontal scrolling.
